AutoVerse is a full-stack automotive discovery platform designed to help users search, explore, compare, and evaluate vehicles through a responsive web interface.

The application combines a JavaScript-based frontend with a Node.js and Express.js backend, MongoDB database, RESTful APIs, user authentication, administrative management tools, and an AI-powered automotive assistant.

## 📌 Project Overview

AutoVerse provides a centralized platform for exploring automotive information and making informed vehicle decisions.

Users can:

- Browse vehicles by category and body type
- Search cars by brand and model
- View detailed vehicle specifications
- Compare multiple vehicles
- Get AI-powered automotive recommendations
- View available vehicle variants
- Create user accounts
- Authenticate through login
- Access responsive vehicle detail pages

The platform also includes an administrative panel for managing vehicle information, variants, specifications, and images.
